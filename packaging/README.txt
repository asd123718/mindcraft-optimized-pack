Mindcraft Offline for Windows x64

Run Mindcraft-Micro-Q4-Setup.exe, select an installation location, then launch Mindcraft
from the Windows Start menu or Mindcraft.bat in the installed folder.

The installer includes Andy 4.2 Micro Q4 and installs without internet.
The local dashboard opens in the
default browser. A fresh install has one idle Andy card. Set the Minecraft
server address and port on its card before joining your game.

The included llama.cpp service can use CUDA or ROCm with a compatible Windows
graphics driver. Micro Q4 can run on the CPU. Minecraft itself is separate.
